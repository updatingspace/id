UpdSpace ID хранит данные аккаунта и помогает входить в подключённые сервисы. Здесь описаны доступные способы управления этими данными.

Кто отвечает за сервис

Оператор UpdSpace ID: физическое лицо Mihhail Matvejev, Российская Федерация.

Новые аккаунты могут создавать пользователи с 18 лет.

По вопросам аккаунта и персональных данных: admin@updspace.com. Укажите, что хотите узнать или изменить. Не присылайте пароль, коды входа, ключи восстановления или копию документа без отдельного запроса.

Какие сведения есть в ID

  • Данные аккаунта: идентификатор, имя пользователя, почтовые адреса и сведения об их подтверждении.
  • Профиль и настройки, которые вы заполнили: имя, дата рождения, телефон, аватар, язык и часовой пояс.
  • Данные для защиты входа: хеш пароля, сведения о ключах доступа и двухэтапной проверке, сеансы, устройства и события входа, включая IP-адрес и сведения о браузере.
  • Связанные способы входа, согласия и разрешения, выданные приложениям.
  • Служебные записи для подтверждения почты, восстановления доступа, отправки писем и обработки запросов на данные.

Что получают приложения

При первом входе ID показывает запрошенные разрешения. Проверить выданный доступ и отозвать его можно в разделе «Приложения».

Отзыв прекращает доступ через ID. Он не удаляет сведения, которые приложение уже получило. За копией или удалением данных, сохранённых самим приложением, обращайтесь в этот сервис.

Копия, исправление и удаление

Данные профиля можно исправить в аккаунте. Доступные действия с данными находятся в разделе «Приватность и данные».

Копия ID содержит сведения из ID. Она не включает базы подключённых сервисов, пароли, ключи и действующие токены доступа.

Чтобы запросить сведения, исправление или удаление, можно также написать оператору. Для защиты аккаунта может потребоваться подтверждение, что запрос отправили вы.

Письма и согласия

ID отправляет служебные письма для подтверждения адреса, входа, восстановления доступа, уведомлений о безопасности и получения копии данных. Подписка на новости пока недоступна. Ранее выданное согласие можно отозвать в разделе «Приватность и данные».
