Что означает результат

Статус «принята» или «выполняется» не означает, что данные уже удалены. Сообщать о завершении можно только после подтверждения очистки.

Для расследования ошибки и повторной обработки используйте операторский журнал и утверждённую команду idctl. Веб-интерфейс пока не выполняет эти действия.
